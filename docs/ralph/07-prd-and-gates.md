# prd.json Schema & Dependency Gates

> Machine-readable project state. Generated by `/ralph-bridge`, consumed by all Ralph commands.

## Top-Level Structure

```json
{
  "version": "string",
  "project": "string — project name",
  "generatedAt": "ISO 8601 timestamp",
  "totalStories": "number",
  "totalStoryPoints": "number",
  "sprints": "number — total sprint count",
  "stories": [],
  "gates": [],
  "metadata": {
    "source": "ralph-bridge",
    "artifacts": ["list of source files used to generate"]
  }
}
```

## Story Object Schema

```json
{
  "id": "E{epic}-S{story}",
  "title": "string — human-readable title",
  "epic": "string — parent epic ID (e.g., E30)",
  "sprint": "string — sprint assignment (e.g., V3-1)",
  "storyPoints": "1|2|3|5|8|13 — Fibonacci estimate",
  "riskLevel": "HIGH|MEDIUM|LOW",
  "storyType": "backend|frontend|both",
  "acceptanceCriteria": ["AC1: testable criterion", "AC2: ..."],
  "passes": "boolean — true when story complete and verified",
  "notes": "string — empty, or prefixed: BLOCKED:|DEFERRED:|Manual:|RESET:",
  "model": "string — preferred AI model (haiku|sonnet|opus)",
  "complexity": "complex|moderate|simple",
  "priority": "P0|P1|P2",
  "dependencies": ["E1-S2", "GATE:SCHEMA_FREEZE"],
  "keyFiles": ["path/to/relevant/file.py"],
  "techSpecFile": "string|null — path to generated tech spec",
  "implementedDate": "string|null — ISO date when completed"
}
```

### Field Semantics

| Field | Values | Notes |
|-------|--------|-------|
| `passes` | `true`/`false` | Only `true` after QA + review pass |
| `notes` | Empty or prefixed | `BLOCKED:` = auto-skipped, `DEFERRED:` = postponed, `Manual:` = done outside loop |
| `dependencies` | Story IDs + Gate IDs | ALL must be satisfied before story is eligible |
| `techSpecFile` | Path or `null` | Set by SM agent during tech spec creation |
| `implementedDate` | ISO date or `null` | Set when `passes` becomes `true` |

## Gate Object Schema

```json
{
  "id": "GATE:NAME",
  "name": "string — human-readable name",
  "triggerStory": "string — story ID that unlocks this gate",
  "unlocked": "boolean — true when trigger story passes",
  "blocksEpics": ["array of epic IDs blocked"],
  "description": "string — what this gate represents"
}
```

### Gate Types

| Pattern | Purpose | Example |
|---------|---------|---------|
| Schema Gate | Locks until data model finalized | `GATE:SCHEMA_FREEZE` |
| Pipeline Gate | Locks until processing pipeline operational | `GATE:EXTRACTION_COMPLETE` |
| AI Gate | Locks until AI components operational | `GATE:AI_COMPLETE` |
| UI Gate | Locks until frontend views functional | `GATE:UI_COMPLETE` |

### Gate Lifecycle
```
Story in progress → Story passes → Gate unlocked → Downstream stories eligible
                                        ↑
                    Manual: /ralph-gate unlock GATE_NAME
```

## Dependency Graph

### Dependency Types
- **Story dependency**: `"E1-S2"` — target story must have `passes: true`
- **Gate dependency**: `"GATE:NAME"` — gate must have `unlocked: true`
- **Mixed**: A story can depend on both stories and gates

### Satisfaction Check
```python
def is_eligible(story, stories_map, gates_map):
    if story.passes:
        return False  # Already done
    if "BLOCKED" in story.notes:
        return False  # Manually blocked
    for dep in story.dependencies:
        if dep.startswith("GATE:"):
            if not gates_map[dep].unlocked:
                return False
        else:
            if not stories_map[dep].passes:
                return False
    return True
```

### Validation Rules
- No circular dependencies
- All referenced story IDs must exist in stories array
- All referenced gate IDs must exist in gates array
- Gate trigger stories must exist

## Story Selection Algorithm

```
1. FILTER: passes === false AND notes NOT contains "BLOCKED" or "DEFERRED"
2. CHECK DEPS: all story deps have passes === true
                all gate deps have unlocked === true
3. SORT by config.selection.sortBy:
   - "sprint-then-sp": sprint order first, then SP ascending (default)
   - "sp-asc": story points ascending globally
   - "risk-desc": HIGH risk first
   - "sprint-only": sprint order only
4. IF config.selection.preferSmallWins: within same sprint, prefer lower SP
5. IF config.selection.maxStoryPoints > 0: exclude stories above threshold
6. SELECT first eligible story
```

## Manual Override Commands

| Command | Action | prd.json Changes |
|---------|--------|-----------------|
| `/ralph-gate show` | Display all gate status | None (read-only) |
| `/ralph-gate unlock ID` | Bypass natural gate flow | `gate.unlocked = true` |
| `/ralph-gate lock ID` | Re-lock a gate | `gate.unlocked = false` |
| `/ralph-skip ID block "reason"` | Block story from selection | `notes = "BLOCKED: reason"` |
| `/ralph-skip ID done "reason"` | Mark manually complete | `passes = true`, `notes = "Manual: reason"` |
| `/ralph-skip ID defer "reason"` | Postpone to later | `notes = "DEFERRED: reason"` |
| `/ralph-retry ID` | Clear block, re-enable | `notes = ""` |
| `/ralph-reset ID` | Reset completed story | `passes = false`, `implementedDate = null` |
| `/ralph-reset ID --keep-spec` | Reset but keep tech spec | Same but `techSpecFile` preserved |

### Override Warnings
- `unlock`: Warns if trigger story not complete (bypasses natural flow)
- `lock`: Warns about downstream stories that become blocked
- `done`: Auto-unlocks gates if story is a trigger
- `reset`: Warns about downstream stories that depend on this one

## Generation

prd.json is generated by `/ralph-bridge` from planning artifacts:
1. Reads epic/story definitions from BMAD planning docs
2. Applies dependency map
3. Applies risk levels and story types
4. Creates gate objects
5. Validates: unique IDs, no circular deps, all refs resolve
6. Writes to project root
