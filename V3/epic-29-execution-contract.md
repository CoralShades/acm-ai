## 1. Charter

### Objective

Collapse the dual-path extraction fork into a single orchestrated pipeline. Every document — regardless of format, building count, or pre-extraction result — flows through `orchestrate_extraction()`. Gate every change behind reproducible benchmarks.

### Non-Goals

- No embeddings, vector search, or semantic retrieval features
- No CopilotKit / AI chat / copilot integration
- No knowledge graph visualization work
- No provider migration (stay on current OpenRouter routing)
- No broad UI redesign beyond extraction/export surfaces
- No new consultant format onboarding (Greencap, Generic)

### Risks

| Risk | L | I | Mitigation |
|------|---|---|------------|
| Broadmeadows regresses below 31/31 | Low | Critical | Gate 2 hard-stops all downstream work |
| Synthetic single-building plan misses content | Low | Med | Uses identical page range as legacy path |
| Docling injection changes Broadmeadows output | Med | Low | Extra records acceptable; validate against ground truth |
| Alexander stays below 36/43 | Med | Med | Separate concern — not a unification blocker |
| Agent decomposition adds latency | Med | Med | Token/latency metrics captured at Gate 3 |
| Scope creep into aspirational features | Med | Med | Out-of-scope list enforced; PM sign-off required for additions |

### External Dependencies

| Dependency | Required By | Status |
|------------|-------------|--------|
| SurrealDB running (Docker) | All stories | Available |
| Broadmeadows PDF + ground truth CSV | S2 | `docs/samplePDF/Clutch_Broadmeadows.*` exists |

| 1 additional benchmark document | S2 | Must be sourced or created |
